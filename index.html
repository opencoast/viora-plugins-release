Highlights

A library that reads what you already have.

Viora does not ask you to import a second copy. It indexes the folders you point at, then stays out of the way while you look.

Core features

A wall for looking. Rooms for reading. A server that stays yours.

The desktop is an Electron window. The library itself is a Go backend — local by default, the same program on a NAS. Media stays on your disks.

The wall

Photos, video, comics and novels in one scroll.

Folders carry a type: Images, Videos, Comics or Novels. Images can be marked photos, illustrations, anime or 3D. The wall then speaks that topic — a media wall, a comic wall that can show an identity you already stored, or a novel shelf. Search and sort stay on the wall. At the library root, a row of what you opened recently sits under the title, and only on this computer.

ImagesVideosComicsNovels

A room for each kind of file

A photo opens full-bleed, with a filmstrip of its neighbours. Video plays the original file, and resting on a video card can cross-fade through preview frames. Comics turn by page or as a spread, left to right or right to left. Novels are their own reading room. Each player takes the window, then returns you to the wall.

PhotosVideoComicsNovels

The file keeps its place in the library

Rename, move or trash from the wall. The library follows the file, so a name change in place does not drop the metadata you already attached. Deleted items sit in a bin you can restore. A Collection can mix loose files, whole folders and live tags — cover, accent and density included — without moving or copying anything on disk. Collections live on this computer.

RenameMoveTrashCollections

The same server, at home or on a shelf

Packaged Viora carries its own local server and starts it only after you choose this computer. Server mode is that binary in Docker: it can hold more than one library, and each library can ask for a password. The desktop already speaks that API. A NAS session belongs to the server; the app does not keep the password.

LocalDockerSeveral libraries

Plugins, when the shelf should reach further

Comic indexes, discovery and downloads are plugins, not a list of sites built into the app. With none installed, those shelves stay hidden. Pack one with viora-plugin, install it, and the same library grows. The app does not know a site until a plugin says so.

SourcesInstall on purpose

Recognition, only after you allow it

Tags and people can come from a model pack running on this machine through ONNX Runtime. You install the pack, accept its licence, then turn recognition on. Faces, labels and a few frames from a video stay in the library. Leave it off, and the wall is only what you filed — comic tags included, when the books already have them.

TagsPeopleOn device

Privacy on the window

The window can frost when focus leaves, and clear when it returns. That is a local display safeguard. Playback choices and the rest of Preferences stay on this machine, beside the database, thumbnails and models — not inside the app bundle.
